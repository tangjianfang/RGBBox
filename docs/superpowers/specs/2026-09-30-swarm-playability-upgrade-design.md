## 二、通用层设计（U1-U8，一次实施四作受益）

### U1 HUD 半透明规范（新共享模块 `games/hud.ts`）
胶囊容器（底 rgba 8-14% + 1px 语义描边 + 高对比前景）、连续血条（分段渐变 绿→黄→红、低值脉冲）、警示 vignette（画布边缘呼吸、可关）、toast 胶囊（3s 自动退）。**贴画布边缘、不进中央 60% 注意区**；对比度 ≥4.5:1（WCAG AA，走现有 --text 语义阶）。

### U2 手柄 Start/Options 四作通用（修 PS5 卡点）
任何已分配手柄 buttons[9]（Xbox Start / **PS5 Options**，standard mapping 一致）：ready/lost/结算态=开局/重开；运行态=暂停/恢复（接 R206 fs 暂停浮层）。修根因：现仅 `pi===0` 分支检测；非 standard mapping 柄兜底扫描（9 失效试 16）+ UI 显示柄连接状态。

### U3 ready 态信息架构（四作统一模式）
首屏 ≤5 项：大号「开局」主按钮（Fitts）+ 核心选择一行胶囊（各作：Survival=战机/人数/难度/场景；TD=地图难度/无尽开关；Tetris=起始等级/模式；Slash=武器/难度）+ 高级项（输入配置/头像/自动预选/词缀/BGM/短局开关）折叠「更多设置」抽屉。**上次选择全记忆（localStorage），重进一键开局**。依据：Hick ≤5 + 渐进披露（NN/g）+ 选择记忆。

### U4 难度框架升级：二档 → 四档（四作全接入）
`Difficulty = 'casual' | 'standard' | 'hard' | 'insane'`，按作持久化（沿用 rgbbox:gamesDifficulty:<id>），**分数倍率 1×/1.5×/2×/3×** 挂街机档案（R198 arcade profile）。各作参数语义化（见下），同一框架不同参数表。

### U5 血条/生命可视化框架
连续条绘制共享（U1），各作语义挂接：Survival=角色 HP 条；TD=**基地生命条**（替代数字）；Slash=**心→血条**；Tetris=**危险压力条**（堆高接近顶部时上升、消行回落——纯视觉预警，不改机制）。受击闪白+数字飘字+无敌帧提示。

### U6 实体尺寸与宽容判定原则（各作参数化）
**命中/受击判定 ≤ 视觉 80%**（商业宽容判定惯例）；实体直径目标 ≤ 画布短边 4%。Survival 全线缩 20-25%；TD 塔与气球命中半径复核；Slash 刀光判定窗校准；Tetris 锁定延迟已有（R199）保持。

### U7 多人/多实体信息自适应布局
成员信息组（血条+关键状态）按成员数自适应：1P 角落卡 / 2P 对角 / 3-4P 网格分列，**组整体按画布宽居中**，随画布 CSS 尺寸缩放（±15%）。四作挂接：Survival 4P、TD+Tetris LAN 双端、Slash 2P 对决。

### U8 击杀/操作 juice（可关）
hit-stop（1-2 帧冻结）、克制屏震（0.2s，boss/大事件）、伤害数字飘字、低血心跳音效（走 sfx/BGM 开关体系）、设置持久化。

## 三、各作特化设计

### Survival（v1 方案保留为核心）
- **敌人 8 种行为正交矩阵**（新增 堡垒/虫群/炮手/分裂体/医疗者，Vampire Survivors 设计法）+ 威胁值加权投放。
- **难度四档 eHP 数值**：休闲 10HP×0.65 / 标准 7×1.0 / 困难 5×1.35 / 炼狱 3×1.6（敌伤系数），容错 16/10/6/3 次——依据：一局 10min 期望受击 1.2 次/分钟 反推。
- 背景六场景三层景深+战斗响应（击杀涟漪/boss 暗场/低 HP 红晕）。

### TD
- 难度四档参数化：lives（30/20/14/10）×敌 HP 系数（0.8/1/1.25/1.5）×起始金（+50%/0/-15%/-25%）——依据 BTD6 现金曲线 vs 波威胁模型（休闲档现金冗余换容错）。
- 气球词缀扩展（克制 2 个新词缀：**regen** 周期回血、**armored** 首段减伤——提高塔组合策略价值）；无尽模式分数倍率挂 U4。
- 基地生命条（U5）+ HUD 半透明（U1）+ 地图主题随波次渐变（背景层次，克制版）。

### Tetris
- 难度=**起始等级**（1/5/9/13，guideline 重力曲线已有 `0.8×0.85^(lv-1)`）+ 对战垃圾行频率系数——单人=纯起始等级，LAN=垃圾行系数。
- 危险压力条（U5 视觉预警）+ 方块渲染质感（圆角+内发光描边，纯绘制层）+ HUD 半透明。
- 手柄 Start（U2）+ ready 精简（U3）。

### Slash
- **心→血条**（标准 100HP、受击 -25~35 按敌型；四档难度调敌速 0.85/1/1.15/1.25 与伤害 0.7/1/1.2/1.4——容错 4/3/2/1 次失误窗口，依据反应时间窗 RT≈0.25s×决策深度）。
- **敌人类型扩展**（行为正交）：格挡型（先破防再斩）/冲刺型（走位压力）/远程投掷型（优先近身）——克制 3 种起步。
- 刀光判定窗宽容化（U6）+ 道场背景层次（U1 体系）+ 2P 对决信息自适应（U7）。

## 五、边界（不做）

不改各作核心循环语义（波次/三选一/塔防经济/锁定延迟/斩击节奏）；不动 LAN 协议与网络层；不加新 npm 依赖；全部纯 canvas 程序绘制；街机档案/成就系统只挂倍率不改结构。

## 六、v3 增补：画面尺寸 × 动态背景 × 多人跟随（2026-09-30 用户追加需求 + 头脑风暴结论）

> 用户原文：「游戏的画面，可以设置或更大一些吗？现在的游戏界面太小了，或者改成动态背景。也自动适应多个玩家——比如 3 个玩家往上移动时，背景画面可以移动。实现动态背景的效果。」

### U9 画面占比提升 + 专注模式（方案 C，四作通用）
- 游戏面板默认占比 ~65% → **85%+**：收窄页面周边 chrome（标题行/边距），HUD 融入画布内（与 U1 半透明联动，不占额外空间）。
- **专注模式**：点击画布进入半沉浸（隐藏周边 chrome、面板满窗口），Esc/再点退出；偏好持久化（rgbbox:gamesFocusMode）。
- 设置项：「画面大小」三档（标准/大/专注默认）——用户可调。

### U10 动态背景系统（方案 A，四作通用，立即做）
- 背景 3 层**视差联动玩家质心**：玩家向上移动 → 背景层按系数 0.05/0.10/0.15 反向偏移（1-4P 全体存活者质心），「世界在动」即时成立。
- 时间流动动画：星尘/云雾漂移、场景色彩 60-90s 缓慢轮转（六场景体系上叠加）。
- 事件响应：boss 登场天色压暗、低 HP 红移 vignette（与 U1 警示联动）、击杀涟漪。
- 实现落点：scene.ts 绘制函数加 `(offsetX, offsetY, t)` 参数（纯绘制，零逻辑侵入）；质心每帧由存活玩家计算（已有 players 名册）。
- **依据**：视差 0.05-0.15 为 2D 舒适区（防动晕）；玩家联动视差是「动态背景」的最小完整实现。

### U11（进阶期权，默认排 S4 仅 Survival）大世界 + 摄像机跟随（方案 B）
- 世界 1800×1040（2× 视口）起步；摄像机=存活玩家**质心跟随 + 20% 死区 + 0.08-0.12 指数平滑**；2-4P **zoom-to-fit**（玩家凸包+边距，缩放钳制 0.7-1.0，分太远自动拉远）。
- 背景程序生成无限平铺（scene 模块扩展）；spawn/索敌/磁吸/拾取全部世界坐标化；玩家出屏软约束（边缘推回）。
- **为什么独立期**：玩法结构级变更（固定竞技场→开放世界），数值（敌密度/刷新节奏）需重调；仅 Survival 适用（TD 固定地图/Tetris/Slash 不适用）；LAN 不受影响（Survival 无 LAN）。
- **用户裁决点**：S4 做不做（可先体验 C+A 效果再定）。
