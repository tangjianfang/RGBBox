# RGBBox 隐私声明

> 版本：2026-10-09（随 PRD-0002 R236 建立）。本声明解释 RGBBox 如何处理摄像头画面与其他本地数据。

## 摄像头与手势识别（核心承诺）

RGBBox 的「体感手势」功能（AI Lab / 小游戏方向控制、灯效环等）会使用摄像头。我们对这段数据的处理规则如下：

1. **画面仅本地推理，零网络上传。**
   摄像头帧只在你的电脑上被送入 MediaPipe 的 WebAssembly（wasm）推理引擎（HandLandmarker / FaceLandmarker，模型文件随应用本地分发）。**任何摄像头画面、任何一帧视频，都不会通过网络发送到任何服务器。**

2. **零落盘。**
   摄像头帧只存在于内存中的临时画布，推理完成后即被下一帧覆盖。应用不会把画面截图、录制或写入磁盘。

3. **关闭即停流。**
   关闭体感开关（或主窗口最小化/隐藏，见下）会立刻停止摄像头流——底层会显式 `stop()` 所有媒体轨道，摄像头指示灯熄灭。摄像头不会在功能关闭后保持占用。

4. **landmark 不出内存。**
   推理输出仅为 21 个手部关键点坐标（landmark）等结构化数值，仅在本地进程间传递用于驱动灯效/UI，不包含图像本身，不写入磁盘、不上传。

5. **主窗口不可见时不采集。**
   应用窗口最小化或隐藏时，体感输入自动暂停并关闭摄像头；窗口恢复后再按你的开关状态重启。

## 其他本地数据

- **灯效配置 / Profile / 游戏战绩 / 遥测统计**：全部保存在本机用户目录，不上传。
- **AI8（GoAmzAI）登录**：仅当你主动打开 AI Lab 的登录窗口时，会在独立分区中加载第三方网站 `ai8.rcouyi.com`；该网站的行为受其自身隐私政策约束。RGBBox 对该登录窗口的会话**默认拒绝全部设备权限**（无摄像头/麦克风等访问理由），仅把你在该站点登录得到的令牌保存在本机用于后续 API 调用。
- **崩溃/调试日志**：写入本机日志文件，用于排查问题，不自动上传。
