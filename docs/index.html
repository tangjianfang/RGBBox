RGBBox

本地优先的多屏 RGB 灯光控制桌面客户端。虚拟 RGB 画布预览、分层特效引擎、音频响应特效、3D 模型查看器，一应俱全。

A local-first Electron desktop client for multi-display RGB lighting. Virtual canvas preview, layered effect engine, audio-reactive effects, and 3D model tooling — all in one app.

On-demand model downloads, local cache, user import (.splat/.ply/.ksplat/.spz), and an LED mapping editor to sync lighting to 3D scenes.

架构

Architecture

🏗️ 清晰的模块架构Clean Modular Architecture

各模块职责分明，易于维护和扩展

Well-separated concerns for maintainability and extensibility

src/main

Electron 主进程 — IPC、显示器拓扑、Profile 存储、屏幕捕获后端、悬浮窗管理

Electron main process — IPC, display topology, profile store, screen capture providers, overlay manager

src/preload

上下文隔离的渲染进程 API 桥接，安全暴露 IPC 接口

Context-isolated renderer API bridge exposing IPC channels securely

src/shared

共享类型定义、IPC 通道名称、默认 Profile 和特效预设

Shared TypeScript types, IPC channel names, default profile and effect presets

src/engine

纯 TypeScript 特效引擎（effects.ts、previewEngine.ts、color.ts），无 UI 依赖

Pure TypeScript effect engine (effects.ts, previewEngine.ts, color.ts) with no UI dependency

src/renderer

React UI — 工作区、显示器映射、分层特效控制、WebGL 预览、特效库、音频分析、小游戏、3D 查看器

React UI — workspace, display map, layered effect controls, WebGL preview, effects library, audio analyzer, mini games, 3D Gaussian Splat viewer

1

下载安装

Download & Install

从 Releases 页面下载适合您系统的安装包（Windows / macOS）。

Grab the installer for your OS (Windows / macOS) from the Releases page.

2

选择特效

Pick an Effect

从 45+ 内置特效中选择，或使用智能随机器一键生成独特风格。支持图层叠加与混合模式。

Choose from 45+ built-in effects or use the smart randomizer to generate a unique style. Stack layers and blend modes.

3

推送到显示器

Push to Displays

启用悬浮窗覆盖，将虚拟画布效果推送到物理显示器，支持全屏或自定义区域。

Enable overlay windows to push the virtual canvas to your physical displays — fullscreen or custom region.
