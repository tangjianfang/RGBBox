RGBBox

本地优先的多屏 RGB 灯光控制桌面客户端，提供虚拟 RGB 画布预览、分层特效引擎、音频响应特效和 3D 模型预览工具。

⬇️ 下载最新版本 📂 查看源码

✨ 核心功能

强大的功能组合，打造极致 RGB 灯光体验

🖥️

多屏虚拟画布

自动发现多显示器拓扑结构，支持热插拔刷新和链接显示器虚拟画布模式，实时预览 RGB 效果。

🎨

25+ 内置特效

涵盖经典、高级、3D 视觉、GPU 3D 和音频响应五大类别，满足各种灯光氛围需求。

🎵

音频响应

支持麦克风或系统音频回环捕获，32 频段 FFT 分析，让灯光随音乐律动。

🧊

3D 高斯泼溅查看器

支持模型下载、本地缓存、用户导入以及 LED 映射编辑器，让 3D 模型与灯光互动。

⚡

Web Worker 引擎

渲染帧在主线程之外处理，WebGL 加速画布预览，保证流畅的 60fps 体验。

📅

定时氛围调度

支持白天/傍晚/夜间时间段自动切换效果，参数自动化支持正弦、三角和脉冲曲线。
