RGBBox

本地优先的多屏 RGB 灯光控制桌面客户端。虚拟 RGB 画布预览、分层特效引擎、音频响应特效、3D 模型查看器，一应俱全。

A local-first Electron desktop client for multi-display RGB lighting. Virtual canvas preview, layered effect engine, audio-reactive effects, and 3D model tooling — all in one app.

性能Performance
⚡

Web Worker 渲染引擎

Web Worker Engine

帧渲染在 Worker 线程完成，WebGL 加速画布预览；引擎在无消费者时（工作区隐藏 / 最小化且无悬浮窗可见）自动暂停，空闲 CPU 接近 0。

Frame rendering in a Worker thread, WebGL-accelerated canvas; the engine auto-pauses when no consumer is active (workspace hidden or minimized with no overlay) to keep idle CPU near zero.

重点功能

Spotlight

🧩 多屏虚拟画布 & 视频墙拼接Multi-display Virtual Canvas & Video Wall

把任意数量的屏幕拼成一块连续的虚拟画布——2D 矩阵拼接、拼缝补偿、角度旋转与同步，一张图无缝铺满整面墙。

Stitch any number of screens into one continuous virtual canvas — 2D matrix tiling, bezel correction, angled rotation and sync, so a single image flows seamlessly across the whole wall.

📐 2D 矩阵拼接

📐 2D Matrix Tiling

按"行 × 列"把面板排成矩阵，引擎自动计算每块面板对应虚拟画布的采样区域，整幅画面行列对齐、连续无错位。

Arrange panels in a rows × columns matrix; the engine computes each panel's sampling region of the virtual canvas so the whole image stays row/column-aligned and continuous.

🪟 拼缝补偿（Bezel Correction）

🪟 Bezel Correction

把屏幕边框当成"画面在后方继续"，让被边框遮挡的内容自动跳过——相邻面板边缘精准衔接，消除断层。

Treats screen bezels as if the image continues behind them, skipping the hidden content so adjacent panel edges line up and seams disappear.

🔄 角度旋转 & 3D 拼接

🔄 Angled Rotation & 3D Stitching

每块面板可独立设置 0°/90°/180°/270° 或任意角度旋转，支持竖屏、斜切、立体造型墙等创意拼接，画面映射依旧同步。

Per-panel rotation at 0/90/180/270° or any angle supports portrait, tilted and sculptural "3D" wall layouts while content mapping stays in sync.

🖼️ 内容适配（Fit）

🖼️ Content Fit

拉伸 / 包含 / 覆盖三种模式，按墙体宽高比智能裁切或留边，源画面与墙面比例不一致时也能正确铺排。

Stretch / Contain / Cover modes crop or letterbox by the wall aspect ratio, so source content maps correctly even when its ratio differs from the wall.
