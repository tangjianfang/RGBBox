## 1. 「商业用途」的可量化验收线定义表

> 锚定方法：消费级手势产品通行标准（Apple Vision Pro 手势追踪 / Pixel Quick Gestures / Leap Motion 教训 / Beat Saber 范式）× 本产品定位（桌面 RGB 灯效玩家 + 迷你游戏玩家，无技术背景）× 仓内文献结论（`docs/reviews/2026-09-20-vision-deep-review.md`：AR 级 <100ms「跟手」阈值、300ms 感知规则、带宽墙 10bits/s 只压高频连续操作、supported gestures 疲劳研究）。
> 判定原则：**商业级 ≠ 更多功能，而是「普通用户在普通环境里第一次就能用、每次都稳、用完还想用」**。核心词汇按「主场景高频动作」定义，不按检测能力定义。

### Top 5 本质差距（性质排序，不是功能数量问题）

1. **价值链断裂：手势控一切，唯独不控灯。** 三个消费方（games / AI 实验室 / 助手）没有任何一条路径改变效果选择、亮度、暂停、场景或 profile（全量 grep 证实：EffectsView/WorkspaceView/hooks/domains/domain 零命中；'vision-input' 总线监听者仅 3 处且都不碰引擎；唯一间接路径=光标 hover 到按钮上 pinch 点击）。RGBBox 的核心资产是 49 效果引擎，「挥手切灯效/捏合调亮度」这一「体感×主场景」的显然结合点完全不存在——**这是「玩具 demo」判定的第一性原因**：检测能力再强，也只在游戏和测试台里打转。
2. **「能力目录」替代了「用户任务」：反馈闭环停在检测层。** 24 能力 9 预留、5 处死消费（表情键名 bug 使 R135 的修饰键从未工作、chord pause/cancel/next 全弃、offPalm 暂停请求无消费者、KeyF 死键、Tetris `c` 死分支）、体检台「只显示不驱动」。demo 证明「能检测 24 种东西」；商业要证明「普通人用 3 个手势完成任务且比鼠标/快捷键更好」。
3. **真机质量证据链缺失：自动化全绿 ≠ 用户可用。** 全部准确率数字来自合成帧；历史上两次全面否定（R136「体验极差」、R143「完全不能用」）都发生在门禁全绿之后；无逐手势置信度、无真机混淆矩阵、无首用漏斗。商业承诺需要「用户环境的度量」，现状只有「实验室的证明」——且 17 天无视觉回归关注期说明连合成证明也停止演进。
4. **首次接触体验无设计。** 入口分散三处且语义不一、游戏侧会话级默认关（每次都从零开启）、无环境预检（暗光用户直接进入最差体验）、无 mini 教学、无「第一个成功动作」设计。A3/A6/A9 三维同时失分都源于此。
5. **工程可见债腐蚀可信度。** 表情链路键名不匹配（宣称的功能从未工作）、vision_input.js 死代码、径向菜单 8/12 视图硬编码 + 过时注释、错误处理一行裸报错。每项都小，但都是用户/评审者亲眼可见的「demo 感」来源。

## 7. 不做清单

| 项 | 理由 |
|----|------|
| EMG/腕带/数据手套等任何硬件方案 | 用户终极约束（memory + R141 条款原文「任何规划不得再提出」） |
| OS 级鼠标/键盘注入 | R131 架构边界（Non-Goals 明示）；系统权限与安全审查复杂度不成比例 |
| 全局常开手势（系统级监听） | Midas Touch 误触（R140 评估定律 2）；「模式内才消费」是既定正确设计 |
| 和弦打字作为产品功能推广 | 6h 训练成本 × 零消费场景（C10）；文献定位即储备杠杆 |
| 全 app 手势光标替代鼠标 | 带宽墙 10bits/s（R140 评估定律 1）+ R143 用户实测否定史；光标仅限助手模式内保留 |
| 注视+捏合（gaze+pinch） | R136 Non-Goals 已裁（handedness 语义不可靠 + 精度未验证），无新证据推翻 |
| 表情识别扩展消费（表情→应用动作） | R132 曾 faceless 回滚、R135 恢复仅检测；微表情税 + 误触率高（文献+仓内结论）；face_engine 保留检测与实验室探索，不做消费方 |
| 云端推理 / 任何视觉遥测 | 单机本地优先隐私姿态（全仓无遥测，保持）；帧数据出本地 = 商业信任反向操作 |
| 通用手势 SDK / 第三方接入 | 单机应用阶段无生态杠杆，纯成本 |
| 更多旧游戏接入手势输入 | R141 裁决「键鼠游戏嫁接手势 = 天花板最低路径」，实测史（R136/R133/R137/R138 四轮修）已证明；新游戏若接须手势原生设计（光刃范式） |
| 「保存自定义场景」外的场景编辑器深化 | 与视觉无关的主线债，不混入本评审 |
