## 0. 一页结论

**因果链：这不是"测试不够多"的仓库，而是"测试够不到发布"的仓库。** 1419 个 it() 引擎域对表化极强，但四道结构性洞让所有绿色证据在发布时刻失效：①**发布链零门禁**——`dist:win = 版本号+clean+build+打包`，测试/快照/运行时验证一概不跑（T1/T4）；②**CI 从未绿过**——R221 加的 typecheck 档因 node20 vs devDep 要求 ≥22.19 在 install 期即红（gh 实测两连 failure，主审 R221 时只验证了本地）；③**逃逸宿主全在覆盖率排除名单**——MiniGamesView/App/AudioStudioView/VideoStudioView 被 vitest.config 排除出阈值，「接线正确性」零防线，R221.7 键盘全失效等 4 起逃逸全部落在「引擎数学有锁、接线无锁」象限（近 30 提交 13/17 个 fix 同象限）（T1）；④**运行时层整体缺失**——47 个一次性 verify 脚本无统一入口无挂载，快照仅 hub 级（`CANVAS_MASK_ALL` 对游戏画布失明）。

**六维评估**：

| 维度 | 现状 | 关键数字 |
|------|------|---------|
| 引擎单测 | **强**（对表化范式） | games 225 / engine 141 / main 293 it() |
| 视图接线 | **无防线** | 逃逸宿主 4 文件全在排除名单；hooks 57% 由 useVisionInput 92% 撑盘、useEngineLoop 4.6% |
| IPC 契约 | **56/60 被引用通道仅桥层断言**；纯零覆盖 37/137 | 通道级行为断言仅 4 个；overlayManager.ts:209 字面量绕常量 |
| 断言质量 | 两极分化 | 3 个零断言行为用例、App.test.tsx:8 等价永真、playSfx 断言次数不敏感（tetris 双播逃逸机制） |
| 视觉/快照 | 骨架扎实+四缺口 | prefers-reduced-motion 灭杀开关在 CSS 有、脚本没用（假阳性根）；crashLog 毫秒文件名碰撞（**兼产品缺陷**） |
| 发布门禁/CI | **不存在→损坏** | dist 无钩子；CI node 版本冲突从未绿 |

**最该先做的（=R222 实施清单）**：

1. **`yarn verify:release` 六层门禁**（T4 骨架）：L0 typecheck→L1 全量→L2 build→L3 快照→**L4 运行时冒烟（47 断言：9 视图+4 游戏环+IPC 往返）**→L5 性能；`predist:win/mac/dir` 钩子天然消除版本号回滚问题
2. **CI 修复**：node20→22（一行，解锁从未绿过的远端门禁）+ ubuntu 全量 test 档（T6 实查 headless-gl 有 linux prebuilt， presumed 风险不存在）
3. **crashLog 文件名碰撞修复**（产品缺陷+flake 根）
4. **ui-snapshot 注入 prefers-reduced-motion**（假阳性根修）
5. **systemSettingsStore/profileStore 坏文件路径补测** + saveProfileAs 的 .bad 不对称修复
6. **overlayManager 字面量→常量**
7. **App.test.tsx 永真修复 + CustomPaintEditor 零断言补断言**（T2 Top2）
8. 接线锁范式化：rAF 量子屏障收编 _helpers + 新增游戏四作「开局→输入→移动」烟测（L4 承载）
