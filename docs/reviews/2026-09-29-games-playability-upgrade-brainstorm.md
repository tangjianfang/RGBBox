## 0. 结论速览

**四作一句话诊断**：

| 游戏 | 强项 | 核心短板 |
|---|---|---|
| Balloon TD Arena | 完整闭环、策略框架齐全 | 波次封顶 12 波无长线；无波次情报；放置决策缺反馈；无主动操作 |

**P0 推荐**（性价比最高的三个）：① 策略教练引擎；② Tetris 现代化；③ Juice 补强包。理由与证据见 §5。

## 1. 现状盘点（证据）

### 1.1 Balloon TD Arena（td.ts，600 行）
- 机制：5 塔种（dart/frost/storm/rail/mint）× 3 级升级、出售返 70%、提前开波奖励（剩余秒×4 折金币）、12 波封顶、20 命、路径固定 S 弯。
- 强项：R98 打磨过表现层（粒子/炮管追踪/弹道尾迹/横幅/震动），R97.2 有升级+提前开波，经济闭环成立。
- 短板：
  - **无波次情报**——下一波组成不可见，frost/rail 的针对性布防无从规划（策略深度的最大廉价缺失）。
  - **无长线**——通关即终，best 分数封顶后失去再玩动机。
  - **放置无反馈**——放塔前不知道「这个格子能覆盖路径的百分之几」，最优摆放全靠试错。
  - **鼠标单击游戏**——波间等待期玩家无事可做，无主动技能参与感。

### 1.2 Nova Swarm（survival.ts 897 行 + swarmMeta.ts 279 行）
- 机制：3 角色、12 强化×稀有度、8 神器（±分数系数）、12 成就、boss 轮盘（道具/属性二选一+分解 XP）、局外商店 6 项×3 级、岛屿推进（boss 杀→传送门→+1 修复+主题换色）、连击链、自适应导演（残血仁慈/满血压迫）。
- 强项：对标 Goobies 的 meta 层完整（R99→R106 连续七轮），是四作系统之王。
- 短板：
  - **构筑只有量变**——12 强化全是线性叠层，没有「两个满级合成质变武器」的进化时刻（Vampire Survivors 最上头的核心机制），后期拿卡无惊喜。
  - **boss 零威胁**——boss 只是慢速大血包，只会追击，无攻击模式，「BOSS INBOUND」的演出与实际威胁不符。
  - **怪凭空出生**——敌人从画布外直接涌入，无 0.5s 出生预警（ Vampire Survivors/Goobies 均有边缘箭头预警），被贴脸围杀感觉「不公平」而非「我失误」。
  - 刷怪上限未设——后期帧率风险（敌群分离是 O(n²)）。

### 1.3 Neon Blocks（tetris.ts，387 行）
- 机制：10×20、7-bag、旋转踢墙（仅 ±1/±2 水平尝试）、软降/硬降、ghost、NEXT×3、消行分 100/300/500/800×等级、每 10 行提速。
- 强项：命令队列+held keys 的架构分离干净，可单测（R100.3 的正确遗产）。
- 短板（与现代 guideline Tetris 的差距，逐条都是廉价可补的）：
  - **无 Hold 槽**——现代方块的第一 QoL，没有它策略上限直接砍半。
  - **无 lock delay**——块一碰堆叠当拍锁死，高难度拼操作时体感「抢拍」。
  - **无 SRS 踢墙表**——T-spin 等 cab 中级技巧物理上不可能完成。
  - **计分原始**——无 T-spin/B2B/连击加成，高手操作与新手同价，无 mastery 表达。
  - **无危险反馈**——堆到高位无任何视觉/听觉警示。

### 1.4 光刃斩击（slash.ts，260 行）
- 机制：60 秒限时、8 向标记块迎面飞来、方向对上即斩、连击乘数（每 5 连 +0.5×）、捏合放清屏弹、错方向断连击。
- 强项：手势即游戏的设计定位准确（R141-C 的 Beat Saber/Fruit Ninja 证据链），动量粒子（R142-L5）有记忆点。
- 短板：
  - **块种单一**——只有「方向块」和 8% 金块两种，60 秒内玩法无变化曲线。
  - **零失败压力**——漏块仅断连击，phase='lost' 只是倒计时归零，永远「打满 60 秒」，无险情无心跳。
  - **反馈缺两样**——无刀光轨迹（只有粒子崩溅）、无 hit-stop 顿帧，斩中「打击感」不到位。

### 1.5 平台层（sfx.ts + MiniGamesView.tsx）
- 音频：12 种合成音效 + 单一 Am 琶音 BGM 循环（280ms/步，不分游戏不分强度）。
- 无全局暂停（仅 TD 有 2× 加速）；无难度预设；无跨游戏任务/每日；`drawOverlay` 在 td/tetris 各复制一份；hub 4 磁贴 + ghost 占位。
- 值得保留的底子：四作引擎全是**纯函数状态机**（tick/draw 分离、命令队列、E2E seam），提示系统可以完全复用这个架构。

## 2. 五维升级框架（本轮的「多维」到底是什么）

| 维度 | 在本项目的含义 | 主要落点 |
|---|---|---|
| 可玩性深度 | 每局有「下一个目标」和「有意义的决策」 | TD 波次情报/无尽、Swarm 进化、Tetris Hold/T-spin |
| 休闲友好 | 随时开一局、随时停、输了不挫败、不必读说明书 | 全局暂停、难度预设、开局引导、失败宽恕 |
| 有趣惊喜 | 局内有变化曲线、有「哇」时刻 | 词缀波、boss 弹幕、连锁块、每日挑战、顿帧 |
| 游戏审美 | 打击感、可读性、演出与威胁匹配 | Juice 包（预警/拖尾/闪光/调色）、BGM 分层 |
| 提示策略 | 不替玩家玩，但在他需要时给一句对的提醒 | 策略教练引擎（纯函数 hint，四作共用） |

设计原则（从上述游戏的公认设计证据提炼，均为本项目已验证过的路线）：
1. **风险-收益可见才叫策略**（TD 提前开波奖励 R97.2 已验证此路数）。
2. **威胁必须被预警才公平**——不公平的失败是劝退第一名。
3. **质变时刻制造回忆**——升级卡从 +5% 变成新武器的那一局，玩家会讲给别人听。
4. **Juice 是零资源审美**——项目「零素材合成」哲学（R99.5/R108）下，顿帧/调色/音调变化就是美术。

## 3. 全平台层提案

### P0-A 策略教练引擎（提示策略的正解）
- **架构**：新 `games/coach.ts`——每作导出 `hints(state): CoachHint[]`（`{ text, tone: 'tip'|'warn'|'praise', priority }`），tick 内每 2–4s 评估一次、同一提示 30s 不重复；UI 在画布下方「教练条」轮播（复用既有 snapshot 通路，纯渲染）。全部纯函数 → 直接单测。
- **各作提示源（示例，可裁剪）**：
  - TD：金币闲置 ≥150 →「考虑升级一座 Rail」；漏怪后 →「第二个拐角是霜塔黄金位」；选中放塔时 →「此格覆盖路径 34%」（联动 §4.1 热力）。
  - Swarm：sprinter 潮出现 →「黄色疾跑者怕环刃/暴击」；升级卡出现时 →「环刃已 2 层，拿满可进化」（联动 §4.2）；满血 → 提示去接传送门。
  - Tetris：堆高超 14 行 →「优先打通左侧竖井」；当前块四向皆堵 →「按 C 存进 Hold」（联动 Hold）；连消 2 次后 →「保持单消也能续连击」。
  - Slash：错方向后 →「块上箭头 = 出刀方向」；连击 ≥15 → 语气转夸奖。
- **开关**：教练条可一键关（`rgbbox:gamesCoach`），尊重高手。
- 工作量约 1.5 人日（引擎 hint 函数 4×0.25d + UI 条 0.5d）。

### P1-A 全局暂停 + 难度预设（休闲的底座）
- 暂停：P/Esc → 覆盖层（继续/重开/回 hub），恢复 3-2-1 倒计时；Sur­vival/Tetris/Slash 三作通用（TD 已有波间节奏，顺带补齐）。约 0.5d。
- 难度预设：每作 ready 态浮层加「休闲/标准」二档——TD 30 命+开局 300 金；Swarm 导演仁慈上限提高+刷怪密度封顶；Tetris 起始等级 1/5/10 自选+提速曲线放缓；Slash 3 心制（见 §4.4）。localStorage 记忆。约 1d。

### P2-A 每日挑战 + 跨游戏任务
- **种子化 RNG**（前置小改造）：新 `games/rng.ts`（mulberry32），四作把 `Math.random` 换成模块级 `rand()`；普通局种子=时钟，每日局种子=`YYYYMMDD`——四作天然获得「每日挑战」（当日固定地形/固定随机序列），成绩单列 daily best + 连续天数。
- 跨游戏任务墙：hub 顶部 3 条每日任务（「TD 建 3 座霜塔」「Tetris 一次 4 消」「Slash 连击 20」），完成点灯——奖励做成 hub 磁贴勋章（装饰性），**不**打通 Swarm 金币钱包（避免经济串味，范围守恒）。
- 约 2d（RNG 改造 0.5d 是体力活但机械）。

### P1-B Juice 补强包（审美的正解，跨四作）
1. **hit-stop 顿帧**：金块/4 消/boss 击杀/bonus 斩瞬间冻结 40–60ms——业界公认性价比最高的打击感手段，rAF 循环里一个 `hitStopUntil` 判断即可，约 0.25d。
2. **出生预警**（Swarm/TD 共用语义）：敌人入场前 0.5s 画布边缘红色箭头闪烁——公平性+可读性双收，约 0.5d。
3. **刀光轨迹**（Slash）：最近 6–8 帧掌心/方向点连成渐隐光带（swipe trail），替代纯粒子，约 0.5d。
4. **锁定闪光 + 消行光束**（Tetris）：落锁白闪、消行横向光束扫过，约 0.25d。
5. **等级调色**（Tetris/Swarm 已有岛屿主题，Tetris 补）：背景/网格色随等级渐进偏移，免费的环境叙事，约 0.25d。

### P1-C BGM 分层（音频审美）
- sfx.ts 已有合成 BGM 管线，扩成：每作一组**调式+速度预设**（TD 沉稳 92BPM / Swarm 急促 132 / Tetris 经典上行 / Slash 鼓点强拍），再挂一个 `tension` 入参（Swarm=血量&敌密度、Tetris=堆高、TD=波次、Slash=倒计时）——高张力时加速度+叠打击乐层，低血量转小调。
- 全程零素材，约 1d。

## 4. 各游戏专向提案

### 4.1 TD：「情报 → 决策 → 长线」三连（约 3 人日）
1. **波次情报预览**（P0 级，0.5d）：下一波组成按既有公式反推展示——「下一波：15 只 · 3 精英（橙）」，波间状态条扩位。这是 TD 策略深度的最大单项：知道下一波是精英潮，frost/rail 的布防才有意义。
2. **覆盖热力提示**（P0 级，0.5d）：放塔悬浮时，路径采样 200 点算覆盖率，格子上显示「覆盖 34%」并高亮当前最优格——把试错变成学习，与教练引擎联动。
3. **无尽模式 + 波次词缀**（1d）：12 波后转无尽，每 3 波挂一条词缀（加速潮/护盾层/分裂怪/迷雾），分数持续冲榜；词缀横幅预告。
4. **主动技能**（0.5d）：两个全局 CD 技——「定点雷击」（点击处 60 伤害）+「时缓领域」（4s 全场减速 40%）——把波间等待变成操作时刻。
5. **金币利息**（P2，0.25d）：每波结算 +5% 余额（上限 +20）——「花还是攒」的经典 TD 决策。
6. **三星评价**（P2，0.25d）：按剩余生命给 1–3 星，hub 磁贴显示，拉复玩。

### 4.2 Swarm：「质变 + 威胁 + 公平」（约 2.5 人日）
1. **强化进化（构筑质变）**（P0 级，1.5d）：定义 3–4 条进化配方，两强化满级后升级卡出现「进化卡」：
   - 环刃3 + 暴击4 → **斩月**（刃径 ×1.6，斩击可暴击）
   - 多重射击3 + 射速5 → **弹幕**（7 向扇形永不间断）
   - 穿透3 + 弹速3 → **光矛**（瞬时射线，贯穿全线）
   - 荆棘3 + 修复2 → **荆棘光环**（周身持续灼烧）
   进化即替换原强化并换绘制形态——升级卡从「+10%」变成「新武器」，一局一个记忆点。纯数据+纯函数配方表，沿用 swarmMeta 模式。
2. **boss 弹幕战**（1d）：boss 每 6s 预警发光 0.8s 后放 8 向慢速弹环（可走位躲），血量 <50% 换螺旋弹——「BOSS INBOUND」的演出从此配得上威胁。新实体 bossBullets 独立列表，不进敌群碰撞。
3. **出生预警**：直接复用 P1-B-2。
4. **新角色 ×2**（P2，0.5d）：「棱镜」（多重视角：+1 弹道但伤害 −20%）、「影」（磁吸半径 ×2 但 maxHp=3）——配进化系统刚好像样。

### 4.3 Tetris：现代化改造（约 2.5 人日，四作中杠杆最大）
1. **Hold 槽**（P0，0.25d）：C/Shift 换持，每块限一次——现代方块第一 QoL。
2. **Lock delay 0.5s + 移动重置**（P0，0.5d，上限 15 次重置防无限拖）——落锁从「抢拍」变成「从容」。
3. **SRS 踢墙表**（P0，0.5d）：标准 kick tables 替换 ±1/±2——T-spin 物理可行，为 4 打基础。
4. **T-Spin / B2B / 连击计分**（P0，0.5d）：3-corner 判定 + guideline 分值（TSD 1200/TST 1600、B2B ×1.5、连击 +50×combo×level），画布浮字演出「T-SPIN DOUBLE!」——高手操作终于有分数表达。
5. **放置提示模式**（P0，0.5d，**提示策略的正主**）：开关打开时，对新块跑 10×4 位置的简易启发式（洞数/高度/凹凸/消行），把最优落点 ghost 加一枚小星标——休闲玩家照着摆就能学，高手关掉。纯函数，40 种摆位暴力枚举每帧成本可忽略。
6. **40 行冲刺模式**（P2，0.25d）：计时冲 40 行，休闲「5 分钟一局」的另一种打开方式。
7. **危险警示**（0.25d）：堆高超 14 行画布边缘红晕+心跳音（复用 sfx tick 变调）。

### 4.4 Slash：「块种 + 心跳 + 打击感」（约 1.5 人日）
1. **三心制**（0.5d）：漏块从「断连击」升级为「−1 心」；每 25 连击回 1 心（上限 3）；心尽即终局结算——60 秒里第一次有真正的险情。
2. **连锁块**（0.5d）：同向 2–3 块前后脚进场（块上挂链环标记），窗口内全斩 →「CHAIN ×3」加成+彩带——眼睛开始看全场而非单块。
3. **假动作块**（P2，0.25d）：飞行中段翻转方向一次（翻转前 0.3s 高频闪烁预告）——「看准再出刀」的策略层。
4. **节奏化出怪**（P2，0.25d）：spawnTimer 量化到 BGM 拍点，速度随音乐渐强——从「打块」到「演奏」。
5. **刀光 + 顿帧**：直接复用 P1-B-1/-3。

### 4.5 Hub（顺手，0.25d）
- 磁贴 hover 微倾斜+accent 辉光、best/星级/daily 勋章位、教练开关入口。

## 6. 风险与不做清单

- **R98 教训驻留**：不摊大饼开新游戏。hub 第五作（2048/打砖块类）仅在四作升级完成后按需另议。
- **引擎纯函数守恒**：所有新机制（hint/进化配方/热力/SRS/T-spin 判定/词缀）一律纯函数进引擎文件，React 只做渲染；教练条走既有 snapshot 通路不新增循环。
- **性能预算**：Swarm 刷怪加密度上限（约 120 活敌）防 O(n²) 失控；Tetris 放置提示每块只算一次；hit-stop 冻结期间不累积 dt。
- **不做**：联网排行/账号体系、外部美术/字体资源（坚持零素材合成）、跨游戏金币钱包（经济串味）、多人/联机。
- **体感兼容**：Slash/Tetris/Swarm 的所有新输入（Hold 键、主动技键）沿用既有 vision key 透传通路，手势玩家不因本轮升级变难。

## 8. 第二轮补充需求（2026-09-29 用户四条）——沉浸 / 手势开关 / 双人 / 局域网

> 用户原话归纳：①全屏要纯游戏界面，提示按游戏内容画在画布合适位置，不要一堆边框栏；顺带反馈「手势控制还不是很稳定」；②全局设置加开关（默认关、持久化），只开时才显示右下角手势模式，避免玩游戏误碰；③部分游戏支持双人——键盘/鼠标/手柄各独立控制一个角色；④局域网联机，RA2 式一人建房组局，加入必须非常方便，网络稳定低延迟。

### 8.1 全屏沉浸模式 = 纯画布（P0，约 3.5 人日）

**现状证据**：`.games-screen.fs` 只是把布局铺成 fixed 层，顶栏/侧栏/状态条仍内嵌（R99.2 的设计），画布高度 `calc(100vh - 210px)` 给周边 UI 留了 210px；升级三选一卡、死亡战报、轮盘、TD 塔商店全是 React 面板。这正是用户说的「很多边框栏，很丑」。

**方案**：全屏态隐藏全部 React 面板（顶栏/侧栏/状态条/教练条），画布占满视口等比放大；所有信息由各引擎在画布内合适位置绘制——项目引擎本来就是 tick/draw 纯分离，画布 HUD 是顺理成章的延伸：

- **共享画布 HUD 组件**（新 `games/hud.ts`）：画布内按钮绘制 + 点击/悬停 hit-test + tooltip + 面板底板，四作共用；React 全屏态只留一个自动隐藏的退出角标（鼠标动才现）。
- **TD**：塔商店画布化（底部横排塔卡 + 快捷键 1–5），选中塔的升级/出售画布内按钮；波次情报/下一波倒计时/教练提示画在画布角落与路径留白区。
- **Swarm**：升级三选一画布化（三卡绘制 + 1/2/3 数字键 + 手势焦点环沿用既有通路）；死亡战报画布化；商店/构筑栏在 fs 直接隐藏（全屏就是纯打）。
- **Tetris/Slash**：本就基本全画布，补 start/lost 覆盖层的画布按钮热区（鼠标可点 + Enter 可按）。
- **Esc 语义**：fs 态 Esc=暂停浮层（接 P1-4），再按 Esc 或点「退出全屏」才退出——避免一键既退暂停又退全屏。
- **手势控件随行**：fs 下 VisionPad/VisionBanner/VisionCursor 一并从 DOM 叠层改为画布内绘制（数据源不变），不再有 DOM 悬浮物。

**手势稳定性反馈的回应**：手势识别稳定性属于 Vision Engine 2.0（R142）工作流，本轮不重做推理层；但游戏侧落两个缓解——①fs 纯画布后手势可视化零 DOM 叠层；②每作灵敏度/死区设置并入难度预设（§P1-A）。若要根治识别率，建议单独立项推 R142 落地（需用户拍板优先级）。

### 8.2 手势模式指示器全局开关（P0，0.25 人日）

**现状**：`.vision-pad`（R132.2）挂在画布右下、`vision.enabled` 即显示，开关只有游戏顶栏的 👁 按钮——鼠标/键盘玩家也会看到它杵在角落。

**方案**：SettingsView 新增「游戏 · 手势视觉指示器」开关，默认**关**，localStorage `rgbbox:visionPadVisible` 持久化；VisionPad 渲染条件改为 `vision.enabled && padVisible`。VisionBanner（状态横幅）与 VisionCursor（悬停光标）是功能件不受影响，只收掉装饰性 pad。设置页已有同构 localStorage 开关模式，纯增量。

### 8.3 本地双人（P1，合计约 4.5 人日）

| 游戏 | 形态 | 输入分工 | 引擎改动 | 工作量 |

### 8.4 局域网联机（RA2 式建房）（P1 末启动，合计约 6.5 人日）

**约束复述**：一人建房组局、加入非常方便、网络稳定低延迟。局域网延迟通常 1–5ms、带宽充裕，是联机最友好环境——不需要广域网那套回滚/预测重炮，**host-authoritative（房主权威）+ 指令中继**就是最稳路线。

**架构**：
- **传输**：Electron 主进程新 `src/main/lan/lanService.ts`——Node 原生 `dgram`（UDP 广播发现）+ `net`（TCP 会话），**零新依赖、零外部服务器、纯局域网**（刻意不做 WAN，网络边界即安全边界）；渲染层走既有 `window.rgbbox` IPC 桥加一组事件。
- **发现（「非常方便」的落点）**：房主建房 → UDP 广播 beacon（房间名/游戏/版本/人数，1s 间隔）；加入方打开「加入」面板自动列出同网段房间，**点一下就进**；支持手输 IP 直连兜底；版本不符拒绝并提示升级。
- **权威模型**：房主跑引擎 tick，客端只发**输入指令**（建塔/升级/技能/移动方向），房主 10–20Hz 广播**状态快照**，客端插值渲染。TD 指令稀疏、快照几 KB @15Hz，LAN 下延迟体感为零。
- **稳定性双保险**：①2s 心跳 + 断线提示（房主可续局/客端转观战）；②快照 hash 对账——与 P2-1 每日挑战共用种子 RNG 改造，双方同种子同版本，发现漂移即重同步。
- **分期**：LAN 基建（发现+会话+IPC+房间 UI）2.5d → 首发 **TD 合作**（指令最稀疏，验证链路最优）1.5d → **Tetris 对战**（事件同步天然低带宽）1d → **Swarm 合作**（快照最重）1.5d。建议等 P0/P1 单机层落地后启动。

**不做**：跨网段/NAT 穿透/公网匹配（与「LAN 像 RA2」定位不符，且是无底洞）；protobuf 等重序列化（自写紧凑 JSON，只挑渲染必需字段）。

## 9. 游戏内容全面 review（第三轮·深度版）

> 方法：以「一名下班后开 RGBBox 顺手点开游戏的玩家」为画像，审计四作的会话形态、跨游戏系统与方案自身体量；对 §3–§8 全部提案做 bloat 风险自查。所有新结论均附代码级取证。

### 9.1 会话形态审计

| | time-to-fun | 一局时长 | 重开摩擦 | 失败 UX | 短局模式 |
|---|---|---|---|---|---|
| TD | ~10s（放第一座塔即决策），但 220 金币+5 塔的开局选择对新手是认知负荷 | 8–12min（12 波封顶） | 低（覆盖层 Start，R97.1） | 仅一行分数 | **无** |
| Swarm | ~5s，但 boss 90s 才来，前 90s 偏平缓 | 开放式 5–15min | 低 | **四作最好**（R101.6 战报） | **无** |
| Tetris | 即时 | 随水平变长，无上限 | 低 | 朴素覆盖层 | **无**（40 行已在 P2） |
| Slash | 键盘即时；**手势玩家需先过相机校准——四作最高的进入摩擦** | 固定 60s（天然短局） | 低 | 倒计时归零即结束，**无险情** | 本身就是 |

横切结论：四作都有「再来一局」的低摩擦（好底子），但**短局矩阵缺三作、失败体验只有 Swarm 及格、开局引导全靠玩家自己摸索**。这直接催生下面的增量提案。

### 9.2 新增代码级取证（本轮 review 发现）

- **F5 Slash 炸弹充能不可见**：`slash.ts` 中 `bombCd` 只参与逻辑（`bomb()` 判定、`tickSlash` 递减），`drawSlash` **从未绘制**——玩家不知道 6s 大招好了没有。
- **F6 TD 放置无悬停预览**：`handleCanvasClick`（MiniGamesView.tsx:774 起）只有**点击后**的「Blocked/Need coins」浮字反馈；`distanceToPath(point) < 42` 的禁放边界与塔射程在悬停时**完全不可见**——强化 R201：悬停即画射程圈+绿/红有效着色，与覆盖热力一起交付。
- **F7 Tetris 提速曲线**：`dropInterval = max(0.08, 0.8×0.85^(lv-1))` 早期过陡（Lv2 即 -15%）、高 Lv 后被 0.08 地板磨平——现代化时顺手换成 guideline 风格分段表。
- **F8 BGM 单曲循环**：四作共用一条 Am 琶音（sfx.ts R108），与「审美」诉求差距最大，R205 维持但分期（见 §9.4）。
- **F9 hub 静态**：磁贴只显示 best 一个数字，无最近战绩/连续天数——daily 与 arcade profile（N2）落地后 hub 才有「活气」。
- **F10 重复的 overlay 绘制**：`drawOverlay` 在 td.ts 与 tetris.ts 各复制一份、样式各异——R206 的共享 `hud.ts` 是系统解，审美统一从去重开始。

### 9.3 跨游戏系统审计

- **meta 深度断层**：Swarm 有角色/神器/成就/局外商店，其余三作只有 best 一个数字。**解法不是把 Swarm 金币搬过去**（经济串味红线），而是给每作各自的 mastery 表达：TD 无尽波数+三星、Tetris 40 行 PB+T-spin 计数、Slash 勋章，统一收进 arcade profile（N2）。
- **视觉语言不统一**：四作 HUD 字号/配色/覆盖层各自为政（F10）。R206 画布化顺带统一 type scale 与 accent 体系——这是「审美」维度最大的单点收益。
- **输入矩阵**：TD=鼠标、Slash=手势/键盘、Swarm=键盘/手柄/手势三源、Tetris=键盘/手势。双人（R208）依赖输入解耦，现状已接近可拆，风险可控。

### 9.4 小而美自审：对 §3/§4/§8 全提案的 bloom 裁剪

「小而美」的判定标准：**每个功能必须让「一局的体验」变好，而不是让「功能清单」变长**。据此裁剪：

| 提案 | 裁决 | 理由 |
|---|---|---|
| TD 金币利息（P2） | **砍** | 「存还是花」的决策位已被提前开波奖励（R97.2）占据，利息是同位重复，只加认知负荷 |
| 跨游戏任务墙（P2-1 一半） | **并入 daily，不做独立系统** | 3 条每日任务就是任务墙的全部，多一层 UI 即 bloat |
| Swarm 新角色 ×2（P2） | **降为 stretch** | 进化合成没验证前加角色是给系统加表面积不是加深度 |
| BGM 张力调制（P1-5） | **分期**：一期只做每作静态调式/速度预设，张力调制二期 | 张力映射依赖各作状态钩子，一次做全风险大收益慢 |
| Slash 节奏化出怪 | **时序绑定 R205 一期后** | 没有分曲 BPM 前量化拍点无意义 |
| TD 三星 | 保留，但展示并入 arcade profile | 单独做一套星级 UI 又是一个边框栏 |

保留不变：教练引擎、Tetris 现代化、Juice 包、全屏沉浸、手势开关、暂停/难度、TD 情报+热力+无尽词缀+主动技、Swarm 进化+boss 弹幕、Slash 三心+连锁+假动作、双人（Swarm/Tetris 先行）、LAN（TD 首发，gate：单机 P0/P1 全绿后启动）。

## 10. 市场调研（外部证据 → 方案映射）

### 10.1 休闲游戏基准（2025）

行业共识基准：casual 品质线 D1 留存 ~30–35%、D7 ≥7%、日活人均游玩 ~10 分钟；time-to-fun 与早期游玩激励被证实同时抬升会话时长与 D7（[Segwise 2025](https://segwise.ai)、[Playio 2025](https://blog.playio.co)）。

**对本项目的翻译**：RGBBox 是本地 Electron 工具，无账号、无埋点服务器——行业 KPI 不直接适用，但体验阈值适用，且可以用本地遥测（§12.0）自测：一局 5–10 分钟、重开间隔 <30s、time-to-fun <15s、每 5 局至少 1 次「新高光」（NEW BEST/T-spin/进化）。**小而美的留存观：不追 D7 数字，追「每一局都值得」**。

### 10.2 对标拆解

- **Vampire Survivors / Brotato**（[玩家社区对比](https://steamcommunity.com)、[心理学拆解](https://platinumparagon.info)）：20–30s 微决策循环 + 局内间歇（升级卡/波间商店）是留存引擎；VS 的已知短板是「解开后无聊」（build 收敛后无新目标）。→ 印证 Swarm 升级卡/轮盘路线正确，**进化合成（R202）补「质变记忆点」**，**TD 无尽+词缀（R201）就是自家对「解开后无聊」的解**。
- **Bloons TD 6**（[版本史](https://bloons.fandom.com)、[v27 更新](https://store.steampowered.com)）：长尾三支柱 = co-op 社交留存 + 限时 boss 事件召回 + 常年免费内容。我们无 live-service 能力 → 词缀波次≈自家「boss 事件」、daily 种子≈「今天不一样」、LAN co-op 对齐其 co-op 逻辑。
- **现代 Tetris 生态（TETR.IO/官方 guideline）**（[dev jam 讨论](https://forum.wickeditor.com)、[规则综述](https://en.namu.wiki)）：SRS+7-bag+Hold+T-spin+B2B 构成技能语言与对抗语言，T-spin/B2B 是「打回去」的攻击倍率核心。→ R199 现代化不是可选项而是**唯一正确方向**；双板对战（R208）的垃圾行机制正是这套语言的对战面。
- **Beat Saber**（R141 已取证）：大目标、低精度、方向标记、节奏宽容——**输入即游戏**。→ Slash 补「心跳」（三心）即可，**不加精度要求**（假动作块是「看准再出刀」不是「出得更准」）。
- **红色警戒2 LAN**：客厅/宿舍插网线即玩的怀旧场景。→ 「点一下就进」是 R209 的产品核心，协议自研轻量优先于通用性。

### 10.3 证据 → 提案映射一览

| 市场证据 | 落到的提案 |
|---|---|
| time-to-fun 抬升 D7 | N6 首局引导、教练引擎 R198 |
| Brotato 波间商店留存 | Swarm 升级卡/轮盘（已有）+ 进化 R202 |
| VS「解开后无聊」 | TD 无尽+词缀 R201 |
| BTD6 co-op/事件 | LAN R209、daily 种子 P2-1 |
| guideline 技能语言 | Tetris 现代化 R199 + 双板对战 R208 |
| Beat Saber 输入即游戏 | Slash 三心/连锁 R203（不加精度） |
| 会话 10min 基准 | 短局矩阵 N5、暂停/难度 R204 |

## 11. 小而美最终形态

**北极星**：任何一局都能在 5–10 分钟内爽完，并让人想立刻再来一局。
三个本地可测代理指标（§12.0 遥测）：①重开间隔 p50 <30s；②一局时长 p50 落在 4–12min；③「新高光」出现率 ≥20% 局（NEW BEST / 首次 T-spin / 首次进化 / 词缀波突破）。

**三原则**：①零素材全合成（音效/音乐/图形全程序生成，已立）；②纯函数引擎+画布即界面（React 只做壳，R206 后全屏即街机）；③每作一个记忆点（TD=词缀波、Swarm=进化、Tetris=T-spin、Slash=连锁）。

**最终优先级矩阵**（三轮合并，含 §9.4 裁剪）：

| 波次 | 内容 | R-N | 工作量 |
|---|---|---|---|
| **P0 单机内核** | 教练引擎(+N6 引导)、Tetris 现代化、Juice 包(+N1 recap)、全屏沉浸纯画布、手势指示器开关 | R198–R200, R206–R207 | ~9.25d |
| **P1 深度** | TD 情报+热力(+N3 预览)+无尽词缀+主动技、Swarm 进化+boss 弹幕、Slash 三心(+N4 充能环)+连锁、暂停+难度、BGM 一期静态预设、短局矩阵 N5 | R201–R205 | ~9d |
| **P2 长线** | daily 种子(+N2 profile)、Slash 假动作、Tetris 40 行、BGM 二期张力 | R205+ | ~3d |
| **P3 社交**（gate：P0/P1 全绿） | 双人（Swarm 合作+Tetris 对战）、LAN（TD 合作首发） | R208–R209 | ~11d |

## 12. OKR 总表（每个新增功能一组）

> 纪律：O=定性抱负（一句人话），KR=可量化（标注度量来源：`单测`/`E2E`/`遥测`/`用户实测`）；每轮交付=一个「季度」，R-N 结题时把 KR 实测值回写 PRD 状态行（对齐既有自检文化）；0.7 分=达标，1.0=超预期。

### 12.0 测量基建（前置，0.5d，并入 R198 一并交付）
**O：不联网也能知道玩家玩得爽不爽。**
- KR1 本地遥测 ring buffer `rgbbox:gamesRuns:<id>`（每作最近 20 局：日期/得分/时长/高光），零网络请求（E2E 断言 network hook 为空）。
- KR2 arcade profile 页渲染四作局数/总时长/streak，数据与 ring buffer 一致（`单测`）。
- KR3 遥测可在设置页一键清空（隐私红线，`E2E`）。

### 12.1 模块北极星（贯穿）
**O：任何一局都能 5–10 分钟爽完并立刻想再来。**
- KR1 重开间隔 p50 <30s（`遥测`，基线待测）。
- KR2 一局时长 p50 ∈ [4,12]min（`遥测`）。
- KR3 「新高光」局占比 ≥20%（`遥测`：NEW BEST/首 T-spin/首进化/词缀突破）。
- KR4 四作 typecheck 0 error + 全量测试 0 失败（工程底线，每轮 `yarn test`）。

### 12.2 R198 策略教练引擎（+N6 首局引导）
**O：新手 3 分钟内学会每个游戏的正确玩法，高手感觉不到它存在。**
- KR1 每作 `hints()` 纯函数 ≥5 组单测覆盖触发条件与 30s 去重（`单测`）。
- KR2 首局 3 步引导：首次进入→第一步提示出现 <2s，完成三步后永不复现（`E2E`）。
- KR3 教练条关闭率 <30%（`遥测`：开关状态统计）。
- KR4 用户真机验收：「提示有用且不烦」（`用户实测`）。

### 12.3 R199 Tetris 现代化
**O：Neon Blocks 成为四作中 mastery 上限最高的游戏。**
- KR1 SRS 踢墙表+3-corner T-spin 判定（TSS/TSD/TST）≥12 单测全绿（`单测`）。
- KR2 Hold/lock delay（15 次重置上限）落地后，同一玩家 20 局平均行数较旧版 +50%（`遥测` 前后对比）。
- KR3 放置提示开启时，新手前 5 局 40 行达成时间 -30%（`遥测`，无基线则首测建立）。
- KR4 T-spin 触发即浮字+顿帧演出，E2E 合成输入打出一次 TSD（`E2E`）。

### 12.4 R200 Juice 补强包（+N1 run recap）
**O：每次命中都有可感知的反馈，每次结束都有一次值得回看的结算。**
- KR1 hit-stop 40–60ms 四作全落地，冻结期间不累积 dt（`单测`）。
- KR2 出生预警 0.5s：Swarm 贴脸死亡占比 -50%（`遥测` 前后对比）。
- KR3 run recap 四作统一：含 delta 与高光，画布内渲染（`E2E` 截图复核）。
- KR4 主观验收「打击感明显提升」（`用户实测`）。

### 12.5 R201 TD 情报+热力+无尽词缀+主动技（+N3 放置预览）
**O：每一波都是一次情报驱动的决策，通关之后还有下一局。**
- KR1 波次预览与实际生成 100% 一致（同种子对照，`单测`）。
