## 1. 已完成优化总结(2026-09-25 → 09-26)

### 1.1 修复(用户报障 → 根因 → 处置)

| # | 报障 | 根因 | 修复 | 条款 |

| 1 | Agent 点了没反应 | 幽灵 `selectedLayerId`(读兜底写不兜底) | 对账守卫 + 纯函数 + 回归测试 | R166 |
| 2 | AI8 模型下载 `fetch failed` | 主进程 Node fetch **不走系统代理**(渲染进程走,故 AI8 页正常) | 下载改走 Electron `net.fetch`(Chromium 栈,跟随代理) | R175.8 |

### 1.3 实证记录

- hf-mirror `model_q8.onnx` **404** → 主模型选 `model_q4.onnx`(291MB,HEAD 200)
- hf-mirror tokenizer 偶发 200+HTML 页(3497B)→ HTML 检测 + 换源重试
- huggingface.co 官方在本网络 **DNS 污染**(直连超时)→ net.fetch 代理通道为主路径
- config.json 真实内容仅 44B(`style_text_to_speech_2` 标记)→ 精确对账替代 >1KB 启发式

## 2. 新打磨方案(P 档,发版后执行;flash 会话可承接,每批独立 R-N + ui:snapshot 门禁)

| 批 | 主题 | 内容 | 验收 | 量 |
|---|---|---|---|---|
| **P-1** | 视觉走查 | 9 view 真机目检(苹果尺复评);agent/voice 专属:空态/加载态/错误态/长文本溢出/窄窗(≤980px)布局/暗色对比度 | 缺陷清单归零或入档 | 0.5 会话 |
| **P-2** | Agent 工具卡 | 结果 >12 行默认折叠(点击展开);diff 预览配色统一(before 红/after 绿);流式光标 done 后移除;工具名+耗时徽标 | 长输出不再撑破 transcript | 0.5 会话 |
| **P-3** | 下载体验 | 逐文件并发下载(2-3 路);失败文件单独「重试此文件」按钮;下载完成徽标动画;磁盘占用统计行 | 320MB 全程可观测、可中断、可续传 | 0.5 会话 |
| **P-4** | 提示词工程 | KERNEL/REACT 系统提示词按 Claude Code 风格迭代(工具选择引导/先读后写/失败重试/简洁收尾);AI8 桥增加「重试轮」上限内自适应 | 冒烟任务(读→建→改→测)成功率 ≥80% | 0.5-1 会话 |
| **P-5** | 声文增强 | Kokoro 流式合成(句级边合成边播)/合成进度条/词典 JSON 导入导出/多音色下拉(4 预置→全部) | 长文本合成不阻塞、可中断续跑 | 1 会话 |
| **P-6** | 测试补齐 | Agent 审批「总是允许」前缀记忆用例/会话恢复边界(损坏 JSONL)/Voice 词典上限;分层覆盖率回归 | 分层阈值不回退 | 0.5 会话 |
| **P-7** | 遗留清理 | RC-2 GPU 3D 多层缺陷 / RC-3 screen-ambient 提示形态 / B-2 `_maskZone` 保留策略(需产品决策) | 逐项立项关闭 | 单独排期 |

**建议顺序**:P-1 → P-2 → P-3(体感最快)→ P-4 → P-5 → P-6 → P-7。P-1 至 P-3 适合 flash;P-4 提示词迭代建议 glm。
