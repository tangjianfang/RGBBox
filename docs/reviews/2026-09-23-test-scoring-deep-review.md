## 7. D8 运行时健康 95 分 —— 深度缺口与方案

### 7.1 根因

探针只回答了「空着的时候干不干净」：0 console、365ms、15MB heap。没回答「忙起来稳不稳」：
- **负载**：R151.4 诊断页有 avg/p95 帧时数据通道（1000/fps 阈值 mini-bar），但自动化从未采样；30fps 目标（R155 报告 §5 workspace 面板自述）无实测。
- **时长**：无 30min+ heap 增长采样（vision/音频流是典型泄漏嫌疑面）。
- **交互**：滑杆拖动/tab 快速切换未纳入 console 监控。

### 7.2 终案（唯一合理路径：探针资产化 + 采样深化）

- 探针脚本从 `%TEMP%` 一次性件转为 `scripts/probe-runtime.mjs`（R155 已验证全部 API，硬化成本半天）；
- 增三采样：①开效果负载 30s → p95 帧时（诊断页数据源直读）；②30min 挂机 heap 曲线（devtools Metrics 或 performance.memory 定点）；③交互脉冲（每 2s 切 tab + 拖滑杆）全程 console/pageerror 监控。
- **验收点**：①负载 p95 ≤ 33ms（30fps 线）；②30min heap 增长 <10%；③交互全程 0 error；④数字入 R155 式报告作对照基线。
- 工作量：1 天。风险级 L1（新增 scripts，不改产品）。
