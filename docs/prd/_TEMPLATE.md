# R-N 增量追加模板

> 在 [`PRD-0002-rgbbox-project-catalog.md`](./PRD-0002-rgbbox-project-catalog.md) 对应章节末尾追加一段 R-N。

## 格式

```markdown
### R<主节号>.<子号> `<kind>` — <一句话说明>

- **状态**: ⏳
- **文件**: `src/...` / `tests/...`
- **验收点**:
  - [ ] 验收 1
  - [ ] 验收 2
- **证据**（自检后填）: ⏳

> (实施并自检后改为：- **状态**: ✅ — <简短证据>)
```

## 编号规则

- 主节用 R1 / R2 / R3 / ...（与 PRD-0002 现有主节对应）；
- 子项用 R1.1 / R1.2 / ... 或 R1.<递增号>（同一主节内单调递增，不重用已 closed 的号）；
- 跨节新建主节时，取下一个未用 R 主号。

## R-N 状态符号

| 符号 | 含义 |
| --- | --- |
| ⏳ | 待实施 |
| 🔄 | 实施中 |
| ✅ | 实施并自检通过（附证据） |
| ⚠️ | 部分通过 / 有 caveat |
| ❌ | 失败，已记入 PRD §8 已知问题 |
| — | 不适用 |

## 反例

- ❌ 跳过 PRD-0002 直接在别的 .md 写需求；
- ❌ 把 R-N 写在 git commit message 当作"文档"；
- ❌ 状态长期停在 ⏳ / 🔄 不推进；
- ❌ 重复使用已 closed 的子号。
