# 双任务功能评审（2026-10-12）：三体主题灯效库 + 窗口句柄截图/显示失真

**用户原话**：「1.灯效库增加三体科幻小说中的一系列高光场景，请增加一个三体主题的灯效库 2.截图功能还需要增加按照根据窗口句柄开始截图的功能，截图之后显示放大失真，请按照截图的分辨率大小自适应显示大小即可。review完成之后按照最高标准执行」

## 0 一页结论

**两个任务都可行且路径清晰，无阻断性风险。**

**任务一（三体灯效库）**：推荐**方案 B——新增 kind + 三体专属分类 tab**（`EffectsView.tsx:312` CATEGORIES 加一行即成）。**铁律：物理 LED 输出永远走 CPU `renderEffectPixel`**（`effectGl.ts:30-46` 头注实证 GPU 2D 只是预览移植）——每个三体效果必须先有 CPU 实现。首批 4 个低成本高签名效果：**三体运动**（八字周期解）、**三日凌空**（三光源）、**水滴镜面**（零噪声光滑）、**引力波广播**（双臂螺旋）；旗舰二向箔二批 CPU 先行。6 个场景判定不做（分辨率不可辨/与现有雷同/光敏风险——R283 教训）。实施前先做 **Phase 0 机制加固**（4 个无守卫雷）。

**任务二（截图）**：两个子问题都定位到根因。**显示失真**＝`previewTransform.ts:27-36` `containRect` 无 ≤1 钳制，小尺寸截图进标注器被拉伸 1.31×~3.97×（用户 12 张真实截图实测无一幸免）——修复=`containRectNat` 一处新增两处受益，坐标系统零连带。**窗口截图**＝推荐路线 A（`desktopCapturer.getSources` thumbnailSize≥窗物理尺寸，主进程直出原生分辨率零依赖）：复用 `snipManager.ts:212` 现成重试器（导出即可）+`captureStore.ts:104` 现成 `addBuffer`（导出即可）+新 IPC 通道+窗口选择器 UI。原生 PrintWindow(3) 留 win32 二期救最小化/WCO。

**评分**（扩展面健康度）：架构 🟢→🟡（核心编译期封闭，但 4 个运行时雷）；捕获链路 🟢（复用面大新增面小）；UX 根因确定性 0.92。

## 2 三体灯效库（要点）

- **机制**：方案 B。CATEGORIES 加 `{ labelKey: 'effects.threebody', kinds: [...] }`；i18n 键 `effect.<kind>` + `effects.preset.<kind>.*` zh/en 双侧（映射类型强制配对）。
- **首批 4**（全 CPU，数学骨架在附录报告）：三体运动（figure-8 周期解+帧级几何缓存）/三日凌空（三光源轨道+era 参数）/水滴镜面（零 fbm+滑动高光）/引力波广播（2θ 四极双臂）。
- **二批**：二向箔降维（CPU 先行，R284 headless-gl 全黑教训）、人列计算机、末日粒子雨。
- **不做 6**：宇宙闪烁（全场同步明暗=R283 平淡实锤+光敏）、死线（≈comet）、独立乱纪元（准静态病）、写实舰队（24×14 不可辨，icosahedral-virus 删除先例）、古筝行动、长文字（5×7 字体 4 字符上限）。
- **Phase 0 加固**（先于内容）：①CATEGORIES 类型化 `satisfies` ②i18n 反向校验补真 ③renderEffectPixel case 穷尽守卫（default 抛错或编译期 never 检查）④EFFECT_3D_KINDS 同步测试。
- **门禁**：新 kind 必入 visual-floor 档位+effects.test RGB 扫描列表；新 tab 必致 effects.png 重立（估算 0.21%>0.1% 门槛）。

## 3 窗口句柄截图 + 显示失真（要点）

- **失真修复**：`containRectNat(container, native)`（k=min(cw/nw,ch/nh,**1**)）替换 AnnotateOverlay fit 计算；视频预览的放大语义不动。可选 P1：状态行显示缩放百分比。
- **窗口截图（路线 A）**：新模块 `src/main/windowSnip.ts`——`getSources({types:['window'], thumbnailSize: 物理尺寸封顶 3840})`→选中 source→thumbnail.toPNG()→`captureStore.addBuffer(buf,'window',窗口名)`；重试复用导出的 `getSourcesWithRetry`；自窗过滤（排除 RGBBox 自己的窗口）；失败码 {ok:false,code}（mac denied 码不堵死跨平台）。
- **IPC**：`src/shared/ipc.ts` 新增 `snipCaptureWindow: 'rgbbox:snip:capture-window'`（sourceId 入参）；preload 白名单+返回反注册。
- **UI**：窗口选择器列表（复用 `index.ts:1178` 既有枚举 IPC——消费方 VideoStudio 已有 320×180 选卡先例）+实时缩略预览；入口放截图功能区。
- **二期（win32 专项）**：koffi PrintWindow(PW_RENDERFULLCONTENT=3) 救最小化/WCO 黑块（memory 有案底；onnxruntime 先例证明非零原生依赖）。
- **验收**（9 条在附录）：记事本窗口截图 PNG 尺寸==客户区 DIP×DPR；遮挡仍完整；363×277 用户截图修复前后清晰度对比等。
